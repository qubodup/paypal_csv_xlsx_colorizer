# paypal_csv_xlsx_colorizer
PayPal CSVs suck (actually my use of PP sucks but don't tell anybody) so this makes all lines that belong to each other have the same color. This is for German language headers CSVs. Throw the code into an LLM to make something useable for your language.

Use https://qubodup.github.io/Hex-Color-Text-Live-Preview/ to test nicer colors.
